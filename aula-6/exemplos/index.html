Propriedade CSS display na Prática

Atividade 1 — Exemplos visuais de block, inline, inline-block, none, flex e grid.

1. display: block

Cada elemento ocupa toda a largura disponível e inicia em uma nova linha.

2. display: inline

Elementos permanecem na mesma linha e ignoram propriedades como width e height.

Inline A Inline B Inline C

3. display: inline-block

Permanece alinhado na mesma linha, mas respeita width, height e espaçamentos completos.

Box 1 (140x60) Box 2 (140x60) Box 3 (140x60)

4. display: none vs visibility: hidden

O item com display: none não ocupa espaço no layout; já visibility: hidden oculta visualmente, mantendo o espaço.

Visível A visibility: hidden Visível B (espaço preservado)
