1. Exemplos de @media (Media Queries)

Largura: -- px

Redimensione a janela do navegador para ver o CSS ativar automaticamente diferentes regras de layout, cores e badges conforme os breakpoints @media.

Desktop ativo (@media min-width: 1024px) — 3 colunas Tablet ativo (@media 641px a 1023px) — 2 colunas Mobile ativo (@media max-width: 640px) — 1 coluna

Breakpoint Desktop

Acima de 1024px, os cartões ficam dispostos em 3 colunas com fundo azulado.

Breakpoint Tablet

Entre 641px e 1023px, o grid adapta para 2 colunas confortáveis.

Breakpoint Mobile & Print

Até 640px, vira 1 coluna vertical. Em @media print, oculta botões.
